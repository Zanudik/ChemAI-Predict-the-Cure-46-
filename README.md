# ChemAI: Predict the Cure (Команда 46)

## Описание проекта
Предсказание трёх целевых показателей химических соединений:
- IC50 - концентрация подавления 50% активности вируса
- CC50 - концентрация токсичности для 50% клеток  
- SI - индекс селективности (CC50 / IC50)

## Данные
- 751 объект в обучающей выборке
- 250 объектов в тестовой выборке
- 214 числовых молекулярных дескрипторов

## Методология

### Предобработка данных
- Заполнение пропусков (медиана для числовых, мода для бинарных)
- Yeo-Johnson преобразование для 118 скошенных признаков
- RobustScaler для масштабирования
- Логарифмическое преобразование целевых переменных

### Модели
Протестированы 9 моделей машинного обучения:
- Linear Regression, Ridge, Lasso
- KNN, SVR
- Random Forest, Gradient Boosting, XGBoost, LightGBM

Лучшая модель: Random Forest
